# Luna's Freebie Creator Kit

A bonus toolkit for planning small, useful freebies with AI—without turning a kind gift into a funnel, a vague promise, or an oversized project. These are original, editable templates. They work with any AI assistant that accepts plain text, or as human-only checklists.

## The pieces fit together

| Artifact | Use it for |
| --- | --- |
| [Profiles](PROFILES.md) | Choose whose real job the freebie should help. These are design hypotheses, not research findings. |
| [Rules](RULES.md) | Keep the experience honest, accessible, privacy-conscious, and genuinely free. |
| [Plan](PLAN.md) | Take one freebie from a clear brief to a checked release in five manageable work sessions. |
| [Prompts](PROMPTS.md) | Ask for a brief, options, copy, production plan, and evidence-based review. |
| [Agent roles](AGENT-PROFILES.md) | Give an AI a bounded job and a clear handoff; roles are ready to copy into your chosen tool. |
| [Reusable skills](SKILLS.md) | Repeat reliable workflows for scoping, making, reviewing, and packaging. The included `SKILL.md` files are Codex-compatible and can be adapted to other tools. |
| [Roadmap](ROADMAP.md) | Improve the freebie in evidence-led stages; future ideas are options, not promises. |

The short version: select a **profile**, follow the **rules**, use the **plan** to define the job, choose a **prompt** and bounded **agent**, run the matching **skill**, then use the **roadmap** only after learning from the first release.

## A 20-minute first pass

1. Pick one profile in `PROFILES.md`—or write a more accurate one from conversations with real people.
2. Use the “Freebie brief” prompt in `PROMPTS.md`. Mark every assumption; do not ask an AI to invent user research.
3. Choose one outcome and one deliverable. Check it against `RULES.md`.
4. Run the “Scope one freebie” skill in `SKILLS.md`. Give the maker agent only that approved brief.
5. Run the reviewer agent and fix any release-blocking issue before sharing.

## Suggested workflow

- Start with one person, one need, one small outcome, and a visible definition of done.
- Prefer a useful standalone download or browser-local tool over an account, a signup wall, or a service dependency.
- Label examples, assumptions, limitations, and any AI-assisted content honestly.
- Keep private details and credentials out of prompts. Check the privacy settings of whichever AI service you choose.
- Package only files the recipient needs. Verify the archive by extracting it and opening the actual entry point.
- Collect only the feedback you need, optionally and transparently. Improve from observed friction, not vanity metrics.
